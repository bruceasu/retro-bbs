## 能力清单

**Web（xterm.js）**：全屏多 pane / CJK 宽度对齐 / 原生 textarea 编辑 / 中英切换（`localStorage` 持久化）

**TUI（Bubble Tea）**：双 pane 布局 / `bubbles/list` 滚动 / `bubbles/viewport` / 原生编辑 / `Ctrl+E` 外部编辑器 / `$USER_HOME/.config/retro-bbs-client/config.toml` 持久化偏好

**服务端**：Go 单二进制 / SQLite（WAL）/ Markdown 文件 / FTS5 搜索 / Argon2id / 连接限制 / 登录频率限制 / 启动一致性检查 / 备份恢复 / MCP

**协议**：WebSocket + JSON，请求/响应带 `id`，无 REST

**i18n**：`i18n.json` 单一源，服务端只发 key + 英文 Default，客户端本地翻译

## 如何真正用起来

**启动 server**：

```powershell
go run .
```

**Web**：打开 http://localhost:8080

**TUI**：另开终端

```powershell
$env:BBS_URL="ws://localhost:8080/ws"
go run ./cmd/tui
```

**MCP（stdio，Claude Desktop / Cursor）**：

`claude_desktop_config.json`：

```json
{
  "mcpServers": {
    "retro-bbs": {
      "command": "<BBS_ROOT>\\retro-bbs.exe",
      "args": ["mcp"],
      "env": { "BBS_ROOT": "<BBS_ROOT>" }
    }
  }
}
```

**MCP（HTTP，远程 Agent）**：

`config.toml`：

```toml
[mcp]
enabled = true
path = "/mcp"
token = "<random-hex>"
```

Agent 配 `https://your-host/mcp` + `Authorization: Bearer <token>`。

**备份**：

```powershell
go run . backup
# → backups/bbs-YYYYMMDD-HHMMSS.zip
```
